# Life Expectancy, Income, and Climate Risk

Project currently in progress...

## Question
Using a 2016 World Bank climate risk assessment, this project asks: 
which countries' life expectancy outperforms or underperforms what 
their income would predict and does climate vulnerability help 
explain the gap? A decade on, has the picture changed for the 
countries flagged as most at risk?

## Data
World Bank data via the `wbgapi` package:
- Life expectancy at birth (`SP.DYN.LE00.IN`)
- GDP per capita, PPP (`NY.GDP.PCAP.PP.CD`)
- Risk to wellbeing from climate/disasters, 2016 (`CC.RISK.WELL.ZS`)
